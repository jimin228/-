# 📋 전사 외근대장 관리 시스템 (Outwork Management System)

> **1팀 · 2팀 · 3팀 · 4팀** 맞춤형 일정 관리, 공식 결재란 인쇄, 엑셀(.xlsx) 자동 생성 및 **Supabase 실시간 클라우드 DB 연동**을 지원하는 올인원 외근대장 솔루션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. ⚡ Supabase 실시간 클라우드 DB 연동 (NEW!)
- **전사 실시간 공유**: 여러 직원이 서로 다른 PC나 모바일에서 접속해도 **동일한 외근 데이터가 실시간으로 동기화**됩니다.
- **Realtime 자동 반영**: 다른 팀원이 외근을 등록하거나 `⚡ 복귀` 버튼을 누르면 **새로고침 없이 화면에 즉시 반영**됩니다.
- **하이브리드 모드**: Supabase가 연동되지 않은 상태에서는 로컬 저장소(LocalStorage)로 안전하게 작동하며, 상단 `[⚡ Supabase 연동]` 버튼으로 언제든 연결할 수 있습니다.

### 2. 📅 월간 캘린더(달력) & 목록 뷰 전환
- `[📋 목록 보기]`와 `[📅 달력 보기]` 전환 지원
- 1팀(파랑) · 2팀(초록) · 3팀(보라) · 4팀(주황) 팀별 고유 색상 배지로 월간 외근 일정을 한눈에 파악할 수 있습니다.

### 3. ⚡ 원클릭 복귀 처리 (`[⚡ 복귀]`)
- 외근 복귀 시 버튼 클릭 한 번으로 **현재 시각이 복귀시간으로 자동 기록**되고 상태가 '복귀완료'로 변경됩니다.

### 4. ⏱️ 외근 소요시간 자동 계산 & 경비 관리
- 출발시간과 복귀시간 입력 시 소요 시간(예: `3시간 30분`)이 자동 산출됩니다.
- 교통비, 유류비, 통행료, 식대 등 외근 경비를 입력 및 관리할 수 있습니다.

### 5. 📊 Excel 파일 다운로드 (.xlsx)
- 상단 `📊 Excel 다운로드` 버튼 클릭 시 **전체 통합 시트 + 1팀~4팀별 개별 시트가 자동 분리 생성**된 실물 엑셀 파일이 즉시 다운로드됩니다.

### 6. 🖨️ 공식 결재란 인쇄 모드 (A4 규격)
- 상단에 **`결재 (담당 | 팀장 | 부서장)`** 서명란이 포함된 표준 비즈니스 양식으로 A4 가로 방향에 최적화되어 깔끔하게 인쇄됩니다.

### 7. 💾 데이터 백업 및 복원
- `💾 백업` 버튼으로 전체 데이터를 `.json` 파일로 저장하고, `📂 복원` 버튼으로 언제든지 복원할 수 있습니다.

## ⚡ Supabase 연동 3단계 가이드

1. **Supabase 프로젝트 생성**:
   - [Supabase](https://supabase.com)에 로그인 후 새 프로젝트를 생성합니다.
2. **테이블 생성 (SQL 복사/실행)**:
   - Supabase 좌측 메뉴의 **[SQL Editor]**로 이동합니다.
   - 본 프로젝트의 **[`supabase_schema.sql`](./supabase_schema.sql)** 파일 내용을 복사하여 붙여넣고 **[Run]**을 누릅니다.
   - *외근 내역 테이블(`outwork_records`), 팀 설정 테이블, 실시간(Realtime) 설정, RLS 정책이 한 번에 자동 생성됩니다.*
3. **웹앱에서 연결**:
   - **[`외근대장.html`](./외근대장.html)**을 열고 상단 **`[⚡ Supabase 연동]`** 버튼을 클릭합니다.
   - Supabase의 `Project URL`과 `anon public key`를 붙여넣고 **[연결 및 데이터 동기화]**를 누르면 끝!

## 📋 입력 및 서식 항목 안내

| 구분 | 항목명 | 설명 |
|:---:|:---|:---|
| **결재란** | 결재 (담당 / 팀장 / 부서장) | 공식 보고용 결재 서명란 |
