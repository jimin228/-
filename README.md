# 📋 4개 팀 외근대장 시스템 안내

본 폴더에는 **4개 팀(1팀, 2팀, 3팀, 4팀)** 체계에 맞춘 외근대장이 준비되어 있습니다.

---

## 🚀 사용 방법

### 방법 1. 웹 브라우저에서 바로 사용하기 (가장 추천! ⭐)
1. **[`외근대장.html`](./외근대장.html)** 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 엽니다.
2. 주요 기능:
   - **외근 등록/수정/삭제**: 일자, 팀(1~4팀), 이름, 직급, 행선지, 외근 목적, 시간, 교통편 등을 손쉽게 등록
   - **팀별 탭 필터링**: [전체], [1팀], [2팀], [3팀], [4팀] 별로 즉시 조회
   - **Excel 다운로드 (.xlsx)**: 상단의 `Excel 다운로드` 버튼 클릭 시, **전체 및 1~4팀별 시트가 분리된 엑셀 파일이 즉시 다운로드**됩니다.
   - **결재란 인쇄**: 상단 `인쇄 (결재양식)` 버튼 클릭 시 **담당/팀장/부서장 결재란**이 포함된 공식 서식으로 A4 출력 가능
   - **팀명 변경**: 상단 `⚙️ 팀명 변경` 버튼을 통해 1팀~4팀의 이름을 실제 부서명(예: 영업1팀, 개발2팀 등)으로 자유롭게 변경 가능
   - **자동 저장**: 브라우저 로컬 저장소에 안전하게 보관되어 페이지를 닫아도 데이터가 유지됩니다.

---

### 방법 2. 파이썬 스크립트로 엑셀 서식 파일 생성하기
- 터미널에서 아래 명령을 실행하면 깔끔한 서식이 적용된 `외근대장_4개팀_통합.xlsx` 파일이 직접 생성됩니다:
  ```bash
  pip install openpyxl
  python 외근대장_생성기.py
  ```

## 📌 포함된 필수 항목
- **결재란**: 결재 (담당 / 팀장 / 부서장)
- **기본 정보**: 번호(No.), 외근일자, 소속팀, 성명, 직급
- **외근 상세**: 방문처(행선지/거래처), 외근 목적, 동행자
- **시간 및 이동**: 출발시간, 복귀시간, 교통편 (법인차, 개인차, 대중교통 등)
- **상태 및 비고**: 진행상태 (외근중 / 복귀완료), 비고/비상연락처
