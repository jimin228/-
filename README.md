# 📋 전사 외근대장 관리 시스템 (Outwork Management System)

> **1팀 · 2팀 · 3팀 · 4팀** 맞춤형 일정 관리, 공식 결재란 인쇄, 엑셀(.xlsx) 자동 생성 및 다운로드를 지원하는 올인원 외근대장 솔루션입니다.

---

## 🌟 주요 기능 (Key Features)

### 1. 🖥️ 대시보드 및 실시간 통계
- **금일 외근 인원 현황**: 오늘 날짜 기준으로 현재 외근 중이거나 외근 예정인 인원수를 실시간 집계합니다.
- **월간 팀별 통계 카드**: 1팀, 2팀, 3팀, 4팀별 이번 달 누적 외근 건수를 한눈에 모니터링할 수 있습니다.

### 2. 🗂️ 4개 팀별 탭 & 필터링
- **팀별 탭 분류**: `전체보기`, `1팀`, `2팀`, `3팀`, `4팀` 탭을 클릭하여 각 팀별 내역만 빠르게 필터링합니다.
- **다양한 검색 필터**:
  - 조회 기간(시작일 ~ 종료일) 설정
  - 진행 상태별 필터 (`외근중`, `복귀완료`)
  - 실시간 검색어 검색 (성명, 직급, 행선지/방문처, 외근 목적, 동행자)

### 3. 📊 Excel 파일 다운로드 (.xlsx)
- 별도의 프로그램 설치 없이 웹 브라우저에서 버튼 하나로 즉시 실물 엑셀 파일이 다운로드됩니다.
- 다운로드 시 **전체 통합 시트**뿐만 아니라 **1팀, 2팀, 3팀, 4팀별 개별 시트**가 자동으로 분리되어 깔끔하게 구성됩니다.

### 4. 🖨️ 공식 결재란 인쇄 모드 (A4 규격)
- 회사 공식 제출용 서식으로 즉시 출력할 수 있습니다.
- 상단에 **`결재 (담당 | 팀장 | 부서장)`** 도장/서명란이 포함된 표준 비즈니스 양식으로 A4 가로 방향에 최적화되어 인쇄됩니다.

### 5. ⚙️ 자유로운 팀명 커스터마이징
- 상단 `⚙️ 팀명 변경` 메뉴를 통해 1팀~4팀의 명칭을 실제 회사 조직도에 맞추어 자유롭게 변경할 수 있습니다. (예: `영업1팀`, `개발2팀`, `마케팅팀`, `인사팀` 등)

### 6. 💾 로컬 자동 저장 (LocalStorage)
- 입력한 외근 데이터는 브라우저 로컬 저장소에 안전하게 보관되므로, 브라우저를 닫거나 새로고침해도 데이터가 사라지지 않습니다.

## 🚀 빠른 시작 가이드

### 방법 1. 웹 브라우저에서 바로 사용 (가장 추천)
1. **[`외근대장.html`](./외근대장.html)** 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge)에서 엽니다.
2. `➕ 외근 등록` 버튼을 눌러 외근 정보를 등록합니다.
3. 등록 완료 후 `📊 Excel 다운로드 (.xlsx)` 버튼을 누르면 엑셀 파일로 바로 저장됩니다.
4. 출력 또는 결재 보고가 필요할 때는 `🖨️ 인쇄 (결재양식)` 버튼을 클릭합니다.

### 방법 2. Python으로 엑셀 템플릿 생성하기
Python 환경에서 표준 엑셀 서식 원본 파일이 필요한 경우 아래 명령어를 실행합니다:

```bash
# 필수 라이브러리 설치
pip install openpyxl

# 엑셀 파일 생성
python 외근대장_생성기.py
```
> 실행 시 현재 폴더에 `외근대장_4개팀_통합.xlsx` 파일이 생성됩니다.

## 📋 입력 및 서식 항목 안내

| 구분 | 항목명 | 설명 |
|:---:|:---|:---|
| **결재란** | 결재 (담당 / 팀장 / 부서장) | 공식 보고용 결재 서명란 |
| **기본 정보** | 번호, 외근일자, 소속팀, 성명, 직급 | 외근자 기본 인적 사항 |
| **상세 내용** | 방문처(거래처/행선지), 외근 목적, 동행자 | 외근 장소 및 주요 업무 내용 |
| **시간 & 이동** | 출발시간, 복귀시간, 교통편 | 이동 수단 (법인차량, 개인차량, 대중교통 등) |
| **상태 & 비고** | 진행상태 (외근중/복귀완료), 비고/연락처 | 차량번호, 비상연락망, 특이사항 |
